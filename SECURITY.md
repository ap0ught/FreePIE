# Security Policy

## Supported Versions

Security fixes are provided on a best-effort basis for the latest code on `master`.

| Version | Supported |
| --- | --- |
| `master` | ✅ |
| Older releases and forks | ❌ |

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting flow when it is available for this repository.

If private reporting is unavailable, do not open a public issue. Instead, contact the maintainers through GitHub with:

- a description of the issue and the affected component
- reproduction steps or a proof of concept
- the impact you expect
- any suggested remediation or workaround

We will investigate reports on a best-effort basis and coordinate public disclosure after a fix or mitigation is available.
